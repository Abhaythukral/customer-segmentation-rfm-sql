# Customer Segmentation using RFM Analysis (SQL)

## Project Overview

This project uses RFM (Recency, Frequency, Monetary) Analysis to segment customers based on their purchasing behavior using PostgreSQL.

## Objectives

- Calculate Recency
- Calculate Frequency
- Calculate Monetary
- Score customers using NTILE(5)
- Segment customers using CASE statements
- Generate business insights

## Tools

- PostgreSQL
- SQL
- GitHub

## SQL Concepts Used

- JOIN
- GROUP BY
- Aggregate Functions
- CTE
- Window Functions
- NTILE()
- CASE
- ORDER BY
